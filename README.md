# Sonny Ray Cafe Website

Official one-page website for Sonny Ray Cafe, located in Hawthorn, Melbourne.

## Description

A bright and welcoming café offering specialty coffee, creative brunch and a dog-friendly patio. This website showcases the menu, location, and booking options.

## Structure

- `index.html` – main HTML structure
- `styles.css` – all styles
- `script.js` – mobile menu functionality
- `images/` – (optional) folder for your own images

## Deployment on Railway

1. Push this repository to GitHub.
2. Go to [Railway.app](https://railway.app) and create a new project.
3. Choose "Deploy from GitHub repo" and select this repository.
4. Railway will detect it as a static site. Set the publish directory to `.` (root).
5. The site will be deployed and you'll get a public URL.

## Customization

- Replace the placeholder images from Unsplash with your own photos.
- Update the contact form action with a service like Formspree to receive messages.
- Add Google Analytics for tracking.
